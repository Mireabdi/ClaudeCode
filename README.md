# Claude Code -projektit

Tähän repoon kokoan IT-tuen portfolioni projektit, jotka olen tehnyt Claude Coden avustuksella. Opiskelen IT:tä Haaga-Heliassa ja haen helpdesk- ja service desk -tehtäviin, joten projektit liittyvät tukityön arkeen: vianetsintään ja koneiden kunnon tarkistamiseen.

Jokainen projekti on omassa kansiossaan, jossa on oma README käyttöohjeineen.

## Projektit

| Projekti | Mitä se tekee | Tekniikka |
|---|---|---|
| [tyoasemakatsastus](tyoasemakatsastus/) | Tarkistaa Windows-koneen peruskunnon (levytila, päivitykset, palvelut, virhelokit, verkko, käynnissäoloaika, muisti) ja tekee tuloksista HTML-raportin | PowerShell |
